# app.moubillixyz

Web/Mobile app of the Mouton / Cabillic family.

## Architecture

- minimalist web development, only very lightweight frameworks
- no db, no server, everything is on the device
- a [PWA](https://fr.wikipedia.org/wiki/Progressive_web_app), meaning a website than can be installed as a mobile app
- installed through a simple Web access but can be used offline afterward, updated implicitly when network is available
- deployed through [gh-pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) the free github static Web hosting solution

## Toolsets

- [Alpine.js](https://alpinejs.dev/)
- [tailwindcss](https://tailwindcss.com/)
